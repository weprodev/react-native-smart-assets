# react-native-smart-assets

A smart assets package to loads images and icons smartly

## Installation


```sh
npm install react-native-smart-assets
```


## Usage


```js
import { multiply } from 'react-native-smart-assets';

// ...

const result = await multiply(3, 7);
```
